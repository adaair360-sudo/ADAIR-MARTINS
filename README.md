# Currículo — Adair Martins

Página única de currículo em **HTML**, **CSS** e **JavaScript**.

## Como ver

Abra `index.html` no navegador ou sirva a pasta:

```bash
python3 -m http.server 8080
```

Depois acesse `http://localhost:8080`.

## O que a página faz

- Layout de uma página, pronto para impressão / PDF
- Tema claro e escuro
- Português e inglês
- Barras de habilidade animadas
- Cópia do e-mail

## Como personalizar

Edite os textos em `index.html` e as traduções em `js/script.js`. Troque o e-mail `adair.martins@email.com` pelo endereço real.
